# Data Digger - E-Commerce Store

## Project Objective

**Data Digger** is a practical MySQL project designed to provide hands-on experience with CRUD operations, SQL clauses, operators, aggregate functions, primary keys, foreign keys, and relational database queries.

The project represents a simple E-Commerce Store using four related tables:

1. Customers
2. Orders
3. Products
4. OrderDetails

## Technologies Used

- MySQL
- SQL
- GitHub

## Tables

### 1. Customers

| Column | Type | Key |
|---|---|---|
| CustomerID | INT | Primary Key |
| Name | VARCHAR(100) | |

| Address | VARCHAR(255) | |

### 2. Orders

| Column | Type | Key |
|---|---|---|
| OrderID | INT | Primary Key |
| CustomerID | INT | Foreign Key |
| OrderDate | DATE | |
| TotalAmount | DECIMAL(10,2) | |

`Orders.CustomerID` references `Customers.CustomerID`.

### 3. Products

| Column | Type | Key |
|---|---|---|
| ProductID | INT | Primary Key |
| ProductName | VARCHAR(100) | |
| Price | DECIMAL(10,2) | |
| Stock | INT | |

### 4. OrderDetails

| Column | Type | Key |
|---|---|---|
| OrderDetailID | INT | Primary Key |
| OrderID | INT | Foreign Key |
| ProductID | INT | Foreign Key |
| Quantity | INT | |
| SubTotal | DECIMAL(10,2) | |

Relationships:

- `OrderDetails.OrderID` → `Orders.OrderID`
- `OrderDetails.ProductID` → `Products.ProductID`

## Queries Performed

### Customers

- Inserted 5 sample customers
- Retrieved all customer details
- Updated a customer's address
- Deleted a customer using CustomerID
- Retrieved customers named Alice

### Orders

- Inserted 5 sample orders
- Retrieved orders for a specific customer
- Updated an order's total amount
- Deleted an order using OrderID
- Retrieved orders from the last 30 days
- Used `MAX()`, `MIN()` and `AVG()` for order amounts

### Products

- Inserted 6 sample products
- Retrieved products sorted by price descending
- Updated a product price
- Deleted an out-of-stock product
- Retrieved products priced between ₹500 and ₹2000
- Retrieved the most expensive and cheapest products using `MAX()` and `MIN()`

### OrderDetails

- Inserted 5 sample order-detail records
- Retrieved details for a specific order
- Calculated total revenue using `SUM()`
- Retrieved the top 3 most ordered products
- Counted how many times a specific product was sold using `COUNT()`

## Assumptions

1. CustomerID, OrderID, ProductID and OrderDetailID are manually assigned unique IDs.
2. Customer 5 is deleted because it has no related order.
3. Order 105 is deleted because it has no related OrderDetails.
4. Product 5 has stock `0`, so it is used for the out-of-stock deletion task.
5. `CURRENT_DATE` is used for order dates so the last-30-days query remains useful whenever the project is executed.
6. `SubTotal` represents the amount generated by each order-detail record.

## How to Run

1. Open MySQL Workbench.
2. Open `data_digger.sql`.
3. Execute the complete SQL script.
4. The script creates the `data_digger` database automatically.
5. Run the queries and observe the results.
